# День 1. База: Aiogram + FastAPI + Render + Sentry

## Что делаем
Поднимаем Telegram-бота на Aiogram 3.x, сервер на FastAPI, вешаем вебхук, подключаем Sentry для ошибок, деплоим на Render.

---

## 1. Регистрации (сделай прямо сейчас, 10 минут)

### 1.1 Telegram Bot Token — @BotFather
1. Открой Telegram → найди `@BotFather`
2. Напиши `/newbot`
3. Название: `Viktor` (или любое)
4. Username: `viktoryourname_bot` (должен кончаться на `bot`)
5. Получишь **токен**. Скопируй его в `.env`:
   ```
   BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
   ```
6. Сразу сделай команды: `/setcommands` → выбери бота → отправь:
   ```
   start — Начать
   help — Помощь
   ping — Проверка
   webhook — Статус
   ```

### 1.2 Sentry — следим за ошибками (бесплатно)
1. Зайди на https://sentry.io/signup/
2. Зарегистрируйся (GitHub аккаунт — быстро)
3. Создай проект → выбери **Python (FastAPI)**
4. Получишь **DSN** вида:
   ```
   https://abc123@o123456.ingest.sentry.io/1234567
   ```
5. Скопируй в `.env`:
   ```
   SENTRY_DSN=https://abc123@o123456.ingest.sentry.io/1234567
   ```

### 1.3 GitHub — репозиторий
1. Зайди на https://github.com
2. Зарегистрируйся (если нет) или войди
3. Создай **новый репозиторий**: зелёная кнопка `New`
   - Name: `viktor-bot`
   - Public (бесплатно)
   - Не ставь галочки, просто Create
4. После создания скопируй ссылку вида:
   ```
   https://github.com/твойник/viktor-bot.git
   ```

### 1.4 Render — хостинг (бесплатно)
1. Зайди на https://dashboard.render.com
2. Зарегистрируйся через GitHub (одной кнопкой)
3. Дай доступ к репозиторию `viktor-bot`
4. Готово, пока ничего не создавай

## 2. Запускаем код локально

### 2.1 Клонируем / создаём проект
Если у тебя нет кода — скопируй файлы из папки `viktor-bot`:

```
viktor-bot/
├── main.py            # Запуск
├── Procfile           # Render поймёт, как запускать
├── runtime.txt        # Версия Python
├── requirements.txt   # Зависимости
├── .env               # Токены (НЕ git'аем!)
├── .env.example       # Шаблон для других
└── app/
    ├── __init__.py
    ├── config.py      # Конфиг
    ├── bot.py         # Создание бота + Sentry
    └── handlers.py    # Команды бота
```

### 2.2 Устанавливаем Python
Если нет Python 3.12:
- Скачай: https://www.python.org/downloads/
- При установке поставь галочку **Add Python to PATH**
- Проверь в терминале:
```bash
python --version
```

### 2.3 Создаём виртуальное окружение
```bash
# В папке viktor-bot
python -m venv venv

# Активируем:
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate
```

### 2.4 Ставим зависимости
```bash
pip install -r requirements.txt
```

### 2.5 Заполняем .env
Открой `.env` и вставь свои токены:
```
BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
SENTRY_DSN=https://abc123@o123456.ingest.sentry.io/1234567
APP_URL=http://localhost:8000        # Пока локально
PORT=8000
```

### 2.6 Запускаем локально
```bash
python main.py
```
Открой браузер: http://localhost:8000 — увидишь `{"status":"ok","bot":"Viktor"}`

В терминале должно быть:
```
INFO:     Started server process [12345]
INFO:     Waiting for application startup.
INFO:     Webhook set to http://localhost:8000/webhook
INFO:     Application startup complete.
```

### 2.7 Тестируем бота
Напиши боту в Telegram:
- `/start` — получишь приветствие
- `/ping` — получишь `Pong!`
- `/webhook` — увидишь URL вебхука

## 3. Деплоим на Render

### 3.1 Загружаем код на GitHub
```bash
# В папке viktor-bot
git init
git add .
git commit -m "Day 1: base bot with FastAPI webhook"
git remote add origin https://github.com/твойник/viktor-bot.git
git branch -M main
git push -u origin main
```

### 3.2 Создаём Web Service на Render
1. Зайди на https://dashboard.render.com
2. Нажми **New +** → **Web Service**
3. Выбери свой репозиторий `viktor-bot`
4. Заполни:
   - **Name**: `viktor-bot`
   - **Region**: `Frankfurt` (EU) — ближе к России/СНГ
   - **Branch**: `main`
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python main.py`
   - **Plan**: **Free** (бесплатно)
5. Нажми **Advanced** → **Add Environment Variable**:
   - `BOT_TOKEN` = твой токен
   - `SENTRY_DSN` = твой DSN
   - `APP_URL` = (оставь пустым, Render сам подставит)
   - `PORT` = `10000`

### 3.3 Ждём деплой
- Render начнёт сборку (2-3 минуты)
- Смотри логи в реальном времени (вкладка **Logs**)
- Когда увидишь `Application startup complete.` — всё готово
- URL будет: `https://viktor-bot.onrender.com`

### 3.4 Меняем APP_URL
В **Dashboard** → **Environment** добавь:
```
APP_URL = https://viktor-bot.onrender.com
```
Нажми **Manual Deploy** → **Deploy latest commit** (перезапустится)

### 3.5 Финальный тест
Напиши боту `/webhook` — должен показать:
```
Вебхук:
URL: https://viktor-bot.onrender.com/webhook
Ошибок: Нет
```

## 4. Как проверить что всё работает

| Шаг | Что должно быть |
|-----|----------------|
| `/start` | Приветствие Viktor |
| `/ping` | Pong! |
| `/webhook` | URL указан, ошибок нет |
| `https://viktor-bot.onrender.com/health` | `{"status":"healthy"}` |
| Sentry Dashboard | 0 ошибок (пока) |

---

## 5. Если что-то пошло не так

**Бот не отвечает** → проверь логи на Render (вкладка Logs)

**Webhook не установлен** → смотри APP_URL в переменных окружения

**Ошибка `BOT_TOKEN не задан`** → забыл добавить переменную в Render

**Sentry ничего не видит** → проверь DSN в `.env` или в Render
